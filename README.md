# 来一卦 · 国风术数

> 可知一生的八字，可决一事的六爻，可应一刻的梅花。
> 看得见每一步根据的透明推演。

一套**纯前端、零后端、可直接部署**的国风术数应用。历法计算基于 MIT 协议的高精度历法库，占法引擎以公有领域古籍（《周易》《增删卜易》《梅花易数》《渊海子平》等）为据，**每一步推演都标注出处**。

## 功能

| 占法 | 定位 | 状态 |
| --- | --- | --- |
| 八字 | 知命之明 · 一生一盘 | 可用：四柱盘 / 五行雷达 / 大运流年 / 神煞 |
| 六爻 | 决事之断 · 一事一验 | 可用：铜钱摇卦 / 纳甲盘 / 十二类断语 |
| 梅花 | 应机之灵 · 随手成卦 | 可用：时间与报数起卦 / 体用断语 |
| 大六壬 | 探微之秘 · 起于时机 | 待续 |

## 本地开发

```bash
npm install
npm run dev        # 启动开发服务器
npm run build      # 类型检查 + 生产构建 → dist/
npm run preview    # 预览构建产物
npm test           # 运行测试（含古籍卦例回归）
```

## 部署到 GitHub Pages

推送到 `main` 分支后，`Actions` 自动构建并部署到 Pages（详见 `.github/workflows/deploy.yml`）。仓库需在 Settings → Pages 中启用 Actions 部署。

也兼容 Netlify / Vercel：构建命令 `npm run build`，输出目录 `dist`。

## 设计原则

- **透明推演**：结果页默认给白话结论，术语盘一键展开，每条断语挂古籍出处。
- **守正有界**：只断所问之事，不判命、寿、健康；结果仅供研究与娱乐参考。
- **水墨丹青**：宣纸米白、墨色、朱砂点睛，支持深色模式与减弱动画偏好。
